# Explainable AI for Formula 1 Pit Stop Strategy Prediction

## 📖 Project Overview

Pit stop decisions are among the most critical strategic choices in Formula 1. Teams must balance tyre degradation, race position, fuel strategy, and pace loss to determine the optimal moment for a stop.

This project investigates whether machine learning models can accurately predict pit stop decisions and, more importantly, explain the reasoning behind these predictions using Explainable Artificial Intelligence (XAI) techniques.

The study focuses on race telemetry and lap-level data from the Formula 1 Belgian Grand Prix at Spa-Francorchamps.

---

## Objectives

The main goals of the project are:

- Predict whether a driver will make a pit stop on the next lap (`PitNextLap`).
- Compare the predictive performance of multiple machine learning models.
- Understand which factors influence pit stop decisions.
- Evaluate the reliability and trustworthiness of explanations generated by XAI methods.

---

## Dataset

The data is extracted from kaggle.com. The author of the dataset is Aadi Gupta.

link: https://www.kaggle.com/datasets/aadigupta1601/f1-strategy-dataset-pit-stop-prediction

The dataset contains lap-by-lap race information collected from Formula 1 telemetry and race timing data.

### Target Variable

`PitNextLap`

- 1 → Driver enters the pit lane on the next lap
- 0 → Driver continues racing

### Features

| Feature | Description |
|----------|-------------|
| `TyreLife` | Number of laps completed on current tyre set |
| `Stint` | Current tyre stint |
| `LapTime` | Current lap time |
| `LapTime_Delta` | Change in lap time compared to previous lap |
| `RaceProgress` | Percentage of race completed |
| `Cumulative_Degradation` | Aggregated tyre degradation indicator |
| `Compound` | Tyre compound (Soft, Medium, Hard) |

### Data Preprocessing

- Missing value handling
- Feature engineering
- One-Hot Encoding for categorical variables
- Stratified train-test split
- Class imbalance analysis

## 🔍 Explainable AI Methods

### Global Explanations

#### SHAP Feature Importance

Measures overall contribution of features across all predictions.

#### SHAP Summary Plot

Visualizes both feature importance and direction of influence.

#### Permutation Feature Importance

Evaluates model dependence on individual features.

#### DALEX Variable Importance

Provides model-agnostic feature ranking.

#### Partial Dependence Plots (PDP)

Shows average marginal effect of selected variables.

---

### Local Explanations

#### SHAP Waterfall Plots

Explains individual pit stop predictions.

#### LIME

Creates local surrogate models around selected observations.

#### ICE (Individual Conditional Expectation)

Visualizes prediction sensitivity for single observations.

---

## Explanation Validation

To assess the robustness of explanations, several sanity checks were performed:

### Feature Shuffling Test

Tests whether feature importance decreases after destroying feature information.

### Randomization Test

Evaluates whether explanations change when model parameters are randomized.

### Dummy Feature Test

Introduces irrelevant variables to verify that XAI methods do not assign artificial importance.

## Most Important Features

Across multiple explanation methods, the following variables consistently appeared as the most influential:

1. **TyreLife**
2. **Stint**
3. **LapTime**
4. **LapTime_Delta**
5. **RaceProgress**

These variables align well with real-world Formula 1 strategy considerations.

---

## Key Findings

- Tyre wear is the strongest indicator of upcoming pit stops.
- Performance degradation is captured effectively through lap time dynamics.
- Tree-based models outperform linear approaches.
- SHAP provided the most consistent and informative explanations.
- Multiple XAI methods converged on similar conclusions, increasing trust in the results.
- Sanity-check experiments confirmed the reliability of generated explanations.
